# NEON FM · 个人说明书

复古未来电台风格的个人网站。调频到霓虹，接收五个频道的信号。

## 五个频道

| 频率 | 频道 | 内容 |
|------|------|------|
| 88.1 | 身份信号 | 我是谁 |
| 92.5 | 进行时信号 | 我在做什么 |
| 96.8 | 未来信号 | 我想做什么 |
| 101.3 | 联络信号 | 怎么样和我链接 |
| 105.7 | 成果信号 | 我的成果 |

## 技术栈

- 纯 HTML / CSS / JavaScript
- 原生 Web Audio（无框架）
- Synthwave 视觉：霓虹渐变、地平线网格、落日、CRT、VHS 故障转场
